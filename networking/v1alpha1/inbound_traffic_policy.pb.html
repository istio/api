InboundTrafficPolicy configures the inbound/server-side listener or filter chain of a sidecar, gateway, or waypoint. DestinationRule configures the proxy’s outbound/client-side connection instead.

The most specific policy applies in full, without merging: resource targetRefs, workload selector with matchLabels, namespace-wide policy, then the mesh-wide default in the configuration root namespace. Ties are resolved by oldest creationTimestamp, then lexicographically by name.

Nonempty selectors are namespace-local, including in the root namespace, and do not attach to waypoints. Legacy Istio gateways use workload selectors. For a waypoint Service, precedence is Service attachment, Service namespace default, then mesh default. The waypoint’s hosting namespace does not supply defaults for Services in other namespaces. Unlike DestinationRule lookup, policy selection does not first consult the waypoint’s configuration namespace. Gateway attachment is supported for Kubernetes ingress Gateways, not waypoints.

For example, compress responses at a Kubernetes ingress Gateway:

apiVersion: networking.istio.io/v1alpha1
kind: InboundTrafficPolicy
metadata:
  name: ingress-compression
  namespace: istio-system
spec:
  targetRefs:
  - group: gateway.networking.k8s.io
    kind: Gateway
    name: ingressgateway
  http:
    compression:
      compressors:
      - brotli:
          quality: 4
        minContentLength: 1024
      - gzip: {}

InboundTrafficPolicy

Field Description
selector
WorkloadSelector

Select workloads by label only in this policy’s namespace, including sidecars and legacy Istio gateway workloads. Nonempty selectors do not attach to waypoints. An absent or empty selector selects the namespace; in the configuration root namespace it defines the mesh-wide default. Mutually exclusive with targetRefs.
targetRefs
PolicyTargetReference[]

Attach to Kubernetes ingress Gateways (group gateway.networking.k8s.io) or Services (empty group or core), in this policy’s namespace. Service attachment is for waypoints and requires a waypoint bound via istio.io/use-waypoint. Waypoint Gateway references are unsupported and reported during reconciliation; they do not affect that target. Other supported references can still apply. HTTPRoute attachment is not supported. Mutually exclusive with selector.
http
HttpSettings

HTTP settings for all ports unless replaced by a port-level entry.
portLevelSettings
PortTrafficPolicy[]

Port-specific settings replace the top-level settings in full. Unset fields use built-in defaults, not the top-level settings. A port entry without HTTP compression disables compression for that port. Duplicate numeric ports are rejected. An unmatched override port is diagnosed during reconciliation without preventing other applicable ports from working. The list is bounded to keep admission uniqueness checks within CEL cost limits.

PortTrafficPolicy

Settings for a specific inbound port.

Field Description
port
PortSelector
Required

Workload port for selector attachment, Service port for Service attachment, or listener port for Gateway attachment. All listeners on this port are affected.
http
HttpSettings

HTTP settings for this port. Unset fields use built-in defaults.

CompressionSettings

HTTP response compression settings. Responses already carrying Content-Encoding are not compressed again. Vary: Accept-Encoding is added to compressible responses. Responses without a matching Accept-Encoding, eligible type, or sufficient size are served unchanged. Compression can expose secrets through response sizes when secret data and attacker-controlled input occur in the same response.

Field Description
compressors
Compressor[]

Compressors use native Envoy negotiation. Client Accept-Encoding q-values govern selection. Equal-q explicit encodings follow client-header order; wildcard preference follows list order. At most one compressor applies. Content types participate in negotiation, but a selected codec failing its minimum-size check does not guarantee fallback to another codec. Missing Content-Length retains native streaming behavior without buffering the body. Each algorithm may appear once. An empty list disables compression.
disableOnEtag
BoolValue

Skip responses with a strong ETag to preserve the validator. Defaults to false.
removeAcceptEncodingHeader
BoolValue

Remove Accept-Encoding before forwarding to the application so Istio owns compression. Defaults to true.

Compressor

A response compressor with its own eligibility settings.

Field Description
minContentLength
UInt32Value

Minimum response size in bytes. Defaults to 30. Consider a higher threshold for high-throughput listeners to avoid spending CPU on very small responses.
contentType
string[]

Eligible Content-Type values. An empty list uses Envoy’s defaults: application/javascript, application/json, application/xhtml+xml, image/svg+xml, text/css, text/html, text/plain, text/xml.

Gzip compression.

InboundTrafficPolicyStatus

Aggregate desired-policy selection, not evidence of Envoy acknowledgment or compressed traffic. There is no per-workload or per-resource targets list. Existing Service/Gateway references remain valid at zero replicas, subject to waypoint enrollment. Selectors matching no workloads report zero counts.

Field Description
conditions
IstioCondition[]

Aggregate conditions distinguish selection, partial/full shadowing, missing targets, unsupported attachments, and no applicable HTTP listener. Ordinary TCP ports on a mixed-protocol target are not errors. Conditions and diagnostics may describe partial success while other applicable targets/ports still work.
workloads
InboundTrafficPolicySelectionCounts

Workload outcomes for sidecar/selector policies and namespace/mesh defaults applied directly to workloads. Waypoint Service outcomes are counted separately.
services
InboundTrafficPolicySelectionCounts

Outcomes for referenced Services and Service-scoped namespace/mesh defaults.
gateways
InboundTrafficPolicySelectionCounts

Outcomes for explicitly referenced Kubernetes ingress Gateways.
diagnostics
InboundTrafficPolicyDiagnostic[]

Bounded aggregate diagnostics, not an enumeration of targets. Includes relevant winning policies and explanations for unsupported or inapplicable configuration, including port overrides matching no target port.

InboundTrafficPolicySelectionCounts

Selection outcomes for one explicitly named category. Counts describe the controller’s desired configuration, independent of connected proxies or xDS ACKs. Each counted item is selected, overridden, or invalid; counts are not combined across workload, Service, and Gateway categories.

Field Description

uint32

Number of candidate workloads or resource references in this category.
selected
uint32

Candidates selected for at least one applicable port. Port-level diagnostics can still be present, so selected does not imply every setting applies.
overridden
uint32

Candidates for which another InboundTrafficPolicy wins in full.
invalid
uint32

Missing, unsupported, or inapplicable candidates. A selector matching nothing has total zero, rather than one invalid resource reference.
